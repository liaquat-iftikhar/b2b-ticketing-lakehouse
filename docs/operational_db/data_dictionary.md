# Data Dictionary — Operational Database

> Database: `event_platform` (PostgreSQL)  
> Schema: `public`

All tables share two system-managed audit columns:

| Column | Type | Description |
|--------|------|-------------|
| `_created_at` | `TIMESTAMP` | Row insertion timestamp. Set once on `INSERT`, never updated. Default: `NOW()`. |
| `_updated_at` | `TIMESTAMP` | Last modification timestamp. Automatically refreshed by the `set_updated_at()` trigger on every `UPDATE`. Default: `NOW()`. |

## organizer

Represents companies or individuals who own and host events on the platform. Organizers sign commission agreements with resellers and appear on all sales of their events.

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `organizer_id` | `UUID` | `PRIMARY KEY` | Surrogate key. Generated by the application layer (UUID v4). |
| `name` | `VARCHAR(255)` | `NOT NULL` | Legal or trading name of the organizer. |
| `email` | `VARCHAR(255)` | `UNIQUE NOT NULL` | Primary contact email. Enforced unique across all organizers. |
| `phone` | `VARCHAR(50)` | nullable | Contact phone number in any regional format. |
| `address` | `TEXT` | nullable | Full postal address. Free-form text to accommodate international formats. |
| `_created_at` | `TIMESTAMP` | `NOT NULL DEFAULT NOW()` | See audit columns above. |
| `_updated_at` | `TIMESTAMP` | `NOT NULL DEFAULT NOW()` | See audit columns above. |

**Trigger:** `trg_organizer_updated_at` — fires `BEFORE UPDATE` to refresh `_updated_at`.

**Referenced by:** `commission_agreement.organizer_id`, `event.organizer_id`, `sale.organizer_id`

## reseller

Represents third-party agents or platforms (B2B resellers) who sell tickets on behalf of organizers. Each reseller may operate from a specific geographic region and hold multiple commission agreements.

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `reseller_id` | `UUID` | `PRIMARY KEY` | Surrogate key. Generated by the application layer (UUID v4). |
| `name` | `VARCHAR(255)` | `NOT NULL` | Trading name of the reseller entity. |
| `email` | `VARCHAR(255)` | `UNIQUE NOT NULL` | Primary contact email. Enforced unique across all resellers. |
| `phone` | `VARCHAR(50)` | nullable | Contact phone number. |
| `city` | `VARCHAR(100)` | nullable | City where the reseller's primary office is located. |
| `country` | `VARCHAR(100)` | nullable | Country of operation. |
| `region` | `VARCHAR(50)` | nullable | Broad geographic region (e.g., `EMEA`, `APAC`, `AMER`). Used for regional reporting and segmentation. |
| `_created_at` | `TIMESTAMP` | `NOT NULL DEFAULT NOW()` | See audit columns above. |
| `_updated_at` | `TIMESTAMP` | `NOT NULL DEFAULT NOW()` | See audit columns above. |

**Trigger:** `trg_reseller_updated_at` — fires `BEFORE UPDATE` to refresh `_updated_at`.

**Referenced by:** `commission_agreement.reseller_id`, `sale.reseller_id`

## commission_agreement

Records the commercial agreement between an organizer and a reseller, defining the percentage of each ticket sale the reseller earns as commission. A pair (organizer, reseller) may have at most one active agreement at a time (not enforced at DB level; handled by application logic).

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `agreement_id` | `UUID` | `PRIMARY KEY` | Surrogate key. |
| `organizer_id` | `UUID` | `REFERENCES organizer(organizer_id)` | The organizer party of the agreement. |
| `reseller_id` | `UUID` | `REFERENCES reseller(reseller_id)` | The reseller party of the agreement. |
| `commission_rate` | `DECIMAL(5,2)` | `NOT NULL` | Commission percentage (0.00–100.00). Example: `15.00` means the reseller earns 15% of each sale they facilitate. |
| `_created_at` | `TIMESTAMP` | `NOT NULL DEFAULT NOW()` | See audit columns above. |
| `_updated_at` | `TIMESTAMP` | `NOT NULL DEFAULT NOW()` | See audit columns above. |

**Trigger:** `trg_commission_agreement_updated_at` — fires `BEFORE UPDATE` to refresh `_updated_at`.

**Referenced by:** `sale.agreement_id`

## ticket

Represents a ticket category (tier) within an event. A single event typically has multiple tiers (e.g., VIP, General Admission, Early Bird), each with its own face value. Individual ticket transactions are recorded in `sale`.

| Column | Type | Constraints | Description                                                                            |
|--------|------|-------------|----------------------------------------------------------------------------------------|
| `ticket_id` | `UUID` | `PRIMARY KEY` | Surrogate key.                                                                         |
| `event_id` | `UUID` | `REFERENCES event(event_id)` | The event this ticket category belongs to.                                             |
| `category` | `VARCHAR(100)` | nullable | Ticket tier or category label (e.g., `VIP`, `General Admission`, `Early Bird`).        |
| `face_value` | `DECIMAL(10,2)` | `NOT NULL` | Official listed price per ticket in the USD. Does not include reseller markup. |
| `_created_at` | `TIMESTAMP` | `NOT NULL DEFAULT NOW()` | See audit columns above.                                                               |
| `_updated_at` | `TIMESTAMP` | `NOT NULL DEFAULT NOW()` | See audit columns above.                                                               |

**Trigger:** `trg_ticket_updated_at` — fires `BEFORE UPDATE` to refresh `_updated_at`.

**Referenced by:** `sale.ticket_id`

## sale

Central fact table. Records every individual ticket transaction on the platform, whether sold directly by the organizer or through a reseller. Denormalizes `organizer_id` and `reseller_id` for query efficiency, avoiding multi-join traversal when filtering by either party.

| Column | Type | Constraints | Description                                                                                                                          |
|--------|------|-------------|--------------------------------------------------------------------------------------------------------------------------------------|
| `sale_id` | `UUID` | `PRIMARY KEY` | Surrogate key.                                                                                                                       |
| `ticket_id` | `UUID` | `REFERENCES ticket(ticket_id)` | The ticket category purchased.                                                                                                       |
| `customer_id` | `UUID` | `REFERENCES customer(customer_id)` | The end customer who made the purchase.                                                                                              |
| `organizer_id` | `UUID` | `REFERENCES organizer(organizer_id)` | Denormalized FK — the organizer whose event was sold. Derived from `ticket → event → organizer` but stored directly for performance. |
| `reseller_id` | `UUID` | `REFERENCES reseller(reseller_id)` | The reseller who facilitated this sale. `NULL` for direct (platform) sales.                                                          |
| `agreement_id` | `UUID` | `REFERENCES commission_agreement(agreement_id)` | The commission agreement governing this sale. `NULL` for direct sales.                                                               |
| `channel` | `VARCHAR(50)` | nullable | Sales channel used by the end customer (e.g., `web`, `mobile-app`, `phone`).                                                         |
| `quantity` | `INT` | `NOT NULL` | Number of tickets purchased in this transaction. Always ≥ 1.                                                                         |
| `unit_price` | `DECIMAL(10,2)` | `NOT NULL` | Actual price charged per ticket in USD. May differ from `ticket.face_value` if the reseller applied a markup.                        |
| `total_amount` | `DECIMAL(10,2)` | `NOT NULL` | Total transaction value. Equals `quantity × unit_price`.                                                                             |
| `commission_amount` | `DECIMAL(10,2)` | `DEFAULT 0.00` | Reseller's commission earned on this sale. Computed as `total_amount × (commission_rate / 100)`. Zero for direct sales.              |
| `source` | `VARCHAR(50)` | nullable | System or origin of the sale record (e.g., `platform`, `reseller_csv`, `api`). Used for data lineage tracking.                       |
| `sale_date` | `DATE` | nullable | Calendar date the transaction was completed.                                                                                         |
| `_created_at` | `TIMESTAMP` | `NOT NULL DEFAULT NOW()` | See audit columns above.                                                                                                             |
| `_updated_at` | `TIMESTAMP` | `NOT NULL DEFAULT NOW()` | See audit columns above.                                                                                                             |

**Trigger:** `trg_sale_updated_at` — fires `BEFORE UPDATE` to refresh `_updated_at`.

## Trigger Function

```sql
CREATE OR REPLACE FUNCTION set_updated_at()
RETURNS TRIGGER AS $$
BEGIN
  NEW._updated_at = NOW();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```

Applied to all seven tables via `trg_<table>_updated_at` triggers. Fires `BEFORE UPDATE FOR EACH ROW`, ensuring `_updated_at` always reflects the wall-clock time of the most recent change without relying on application code.
